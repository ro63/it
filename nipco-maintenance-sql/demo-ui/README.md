# پیش‌نمایش ظاهر برنامه (بدون دیتابیس)

این پوشه یک بیلد **فقط-نمایشی** از رابط کاربری است که با داده‌های نمونه کار می‌کند
و به SQL Server یا API نیاز ندارد. برای دیدن ظاهر برنامه:

1. فایل `index.html` را با دوبار کلیک در مرورگر باز کنید، یا
2. پوشه را روی هر وب‌سرور ساده سرو کنید:

```bash
python3 -m http.server 8000    # سپس http://localhost:8000
```

ورود در حالت نمایشی: `takhti` و رمز `123456` (یا هر کاربر دیگری از فهرست صفحه ورود).

> این بیلد برای بازبینی ظاهر است، نه برای استفاده واقعی. داده‌ها از `src/api/demo.ts`
> می‌آیند و در نسخه اصلی/تولیدی وجود ندارند. برای ساخت دوباره:

```bash
npm run build:demo     # خروجی در dist/ (همان محتوای این پوشه)
```
