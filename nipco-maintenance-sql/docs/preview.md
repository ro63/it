# دیدن ظاهر برنامه بدون دیتابیس (Demo)

سه راه برای بازبینی رابط کاربری، بدون نیاز به SQL Server و API:

## ۱) یک فایل HTML (مطمئن‌ترین)

`NIPCO-demo-single-file.html` — کل برنامه (CSS، JS، آیکون و داده نمونه) در یک فایل:

* فایل را دانلود کنید و در ویندوز دوبار کلیک کنید (بدون سرور، بدون اینترنت کار می‌کند)
* یا در پنل فایل‌ها بازش کنید

ورود: `takhti` / `123456`.

## ۲) پوشه بیلد دمو

`demo-ui/index.html` (نسخه چندفایلی همان بیلد):

* دوبار کلیک، یا `python3 -m http.server 8000` داخل پوشه

## ۳) اجرای state دمو با Vite

```bash
npm install
npm run dev:demo          # http://localhost:5173
```

## ۴) ساخت مجدد

```bash
npm run build:demo        # خروجی: dist/  (سپس در demo-ui کپی کنید)
```

> این حالت فقط با `VITE_DEMO=1` (فایل `.env.demo`) فعال می‌شود. بیلد معمولی
> (`npm run build`) هیچ داده نمونه‌ای در خود ندارد و به API واقعی وصل می‌شود.
