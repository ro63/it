# دیدن ظاهر برنامه بدون دیتابیس (Demo)

سه راه برای بازبینی رابط کاربری، بدون نیاز به SQL Server و API:

## ۱) فایل آماده (ساده‌ترین)

پوشه `demo-ui/` یک بیلد کامل و مستقل است:

* `demo-ui/index.html` را از پنل فایل‌ها انتخاب کنید و Preview بگیرید، یا دوبار کلیک کنید، یا
* `python3 -m http.server 8000` داخل همان پوشه و باز کردن `http://localhost:8000`

ورود: `takhti` / `123456` — همه صفحات با داده نمونه کار می‌کنند.

## ۲) اجرای حالت demo با Vite

```bash
npm install
npm run dev:demo          # http://localhost:5173
```

## ۳) ساخت مجدد بیلد نمایشی

```bash
npm run build:demo        # خروجی: dist/
```

> این حالت فقط با `VITE_DEMO=1` (فایل `.env.demo`) فعال می‌شود. بیلد معمولی
> (`npm run build`) هیچ داده نمونه‌ای در خود ندارد و به API واقعی وصل می‌شود.
